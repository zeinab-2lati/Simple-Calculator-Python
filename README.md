# Simple-Calculator-Python
A simple calculator program written in Python that performs addition, subtraction, multiplication, and division with error handling.
This is a simple calculator program written in Python

Features:
Addition (+)
Subtraction (-)
Multiplication (*)
Division (/)
Error handling for invalid number input
Error handling for division by zero

How It Works:
The user enters two numbers and selects a mathematical operator.
The program then performs the selected operation and displays the result.
If the user enters an invalid value, the program displays an error message.
If the user tries to divide a number by zero, the program displays an appropriate error message

Technologies Used:
Python
Functions
Conditional Statements
Try and Except
